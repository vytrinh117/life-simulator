## Confirmed root cause

In authoritative `src/modules/schoolday4c1.js`, rendered buttons used `data-school-home-4c1="1"` and `data-school-go-4c1="1"`. The canonical handler `schoolDayClick4C1(b)` looked up `b.dataset.schoolHome4c1` and `b.dataset.schoolGo4c1`; browser DOM mapping produces `schoolHome-4c1` / `schoolGo-4c1` instead. Both event conditions were therefore false. The rendered buttons were clickable but never reached the travel helper; no JavaScript exception was thrown.

**Pre-fix proof:** `qa/t_hotfix_school_nav.py` clicked real DOM buttons (not helper methods), obtaining **9/15 PASS, 6 expected failures**: the School → Home and Home → School UI paths both remained at their original locations and clock times. Direct backend Go Home succeeded in the same test. See pre-hotfix run captured outside the release ZIP during verification.
